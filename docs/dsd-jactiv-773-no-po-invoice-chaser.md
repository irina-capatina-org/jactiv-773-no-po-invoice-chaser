## 1. Solution Overview

The No-PO Invoice Chaser automation queries Coupa daily for invoices in draft or new status from the past 7 days, filters out credit notes and invoices with linked purchase orders, and posts a summary to Slack if qualifying invoices are found. The AP SME receives a notification with the count, date range, and a link to the Coupa invoice list for manual review and PO linking.

| Component | Role | Entry Point | Location |
|---|---|---|---|
| no-po-invoice-chaser-api | Primary API Workflow | HTTP POST, cloud-triggered | `code/no-po-invoice-chaser-773/no-po-invoice-chaser-api/Workflow.json` |

## 2. As-Built Architecture

```
┌─────────────────────────────────────────────┐
│  no-po-invoice-chaser-api (API Workflow)   │
│                                             │
│  1. Compute 7-day date window              │
│  2. Query Coupa draft/new invoices         │
│  3. Filter: exclude credit notes & PO-linked│
│  4. Count qualifying invoices              │
│  5. If count > 0:                          │
│     - Compose Slack Block Kit message      │
│     - POST to Slack chat.postMessage       │
│     - Validate response                    │
│  6. Return status, count, sent flag        │
└─────────────────────────────────────────────┘
        │                          │
        ▼                          ▼
    Coupa REST API          Slack POST API
    (status=draft,new)      (chat.postMessage)
```

The workflow executes as a single sequence with one conditional branch (qualifying count > 0). Date computation uses JavaScript for 7-day window from run date. Coupa query uses HTTP Connector to POST to UiPath HTTP proxy with Coupa credentials. Slack notification uses HTTP Connector to POST to Slack API endpoint. No inter-project calls; no retry loops. Silent on zero matches (no notification sent).

## 5. Operations Runbook

### Trigger and Schedule
API Workflow triggered via HTTP POST (cloud-triggered). Scheduled weekday at 10:00 Romania time (EET/EEST) by external orchestrator. Manual execution supported via HTTP client with empty body.

### Expected Runtime
Typical run: 3–5 seconds (Coupa query + JavaScript processing + Slack post). Depends on Coupa response time and invoice count.

### Normal Log Output
```
qualifying_count=<N>
slack_sent=<true|false>
```
Where N is the number of invoices without linked POs, and slack_sent is true only if N > 0.

### Success Response
```json
{
  "status": "Successful",
  "qualifying_count": <N>,
  "slack_sent": <true|false>
}
```

### Prerequisites
1. **Coupa connection active** — Verify `uipath-coupa-coupa` connection exists and credentials valid. Test: call GET `/invoices?limit=1` via UiPath HTTP Connector.
2. **Slack connection active** — Verify `uipath-salesforce-slack` connection exists and bot token valid. Test: call POST `chat.postMessage` with channel='WLX9BD8FN'.
3. **Slack channel accessible** — Bot token must have `chat:write` scope; channel `WLX9BD8FN` must exist and bot must be member.
4. **No overrides needed** — All connection IDs, channel ID, date window logic, and query parameters are confirmed facts from SDD §4. No configuration changes required before first run.
